# Web Development Lab&#x20;

### 1. About the Project

This repository is created as part of the **Web Development Lab** to understand and practice the fundamentals of terminal navigation, project folder management, Git version control, and GitHub repository management. The main purpose of this module is to develop practical knowledge of managing web development projects, tracking code changes, working with feature branches, and maintaining proper project documentation. This repository contains practical assignments P1 to P13 completed during the lab sessions.

### 2. Objectives

- To understand terminal commands and project folder navigation.
- To learn how to create and manage project directories and files.
- To understand Git version control and its importance in software development.
- To create and manage repositories using GitHub.
- To perform initial commits and track project changes.
- To understand feature branches and the Git branching workflow.
- To create project documentation using README.md.
- To learn version tagging and release management.

### 3. Technologies and Tools Used

- **HTML5:** Used to create the structure of web pages.
- **CSS3:** Used to style and design web pages.
- **JavaScript:** Used to add interactivity to web pages.
- **Git:** Used for version control and tracking project changes.
- **GitHub:** Used for hosting and managing repositories online.
- **Visual Studio Code:** Used as the code editor.
- **Terminal / Command Line:** Used to execute commands and navigate project folders.

### 4. Practical Assignments

**P1: Project Folder and Terminal Navigation**

- Created and managed project folders.
- Practiced commands such as `pwd`, `ls`, `cd`, `mkdir`, and `touch`.
- Learned directory navigation.

**P2: Portfolio Repository with an Initial Commit**

- Created a personal portfolio project.
- Initialized Git using `git init`.
- Tracked files and created the initial commit.
- Uploaded the project to GitHub.

**P3: Feature-Branch Git Workflow**

- Created feature branches.
- Committed project changes.
- Merged feature branches into main.
- Practiced Git branching workflows.

**P4: GitHub README and Version Tags**

- Created project documentation.
- Added README.md.
- Created version tags.
- Practiced version management.

**P5: Semantic Bio**

- Practiced semantic HTML elements.
- Created a structured personal biography page.

**P6: Portfolio HTML**

- Created a portfolio webpage using HTML.
- Organized sections such as About, Skills, Projects, and Contact.

**P7: CSS Tokens**

- Practiced CSS variables and reusable design tokens.
- Applied consistent colors, fonts, and spacing.

**P8: CSS Positioning**

- Practiced CSS positioning properties.
- Worked with static, relative, absolute, fixed, and sticky positioning.

**P9: Responsive Flexbox**

- Created responsive layouts using Flexbox.
- Practiced flexible alignment and spacing.

**P10: Advanced Flexbox**

- Practiced advanced Flexbox properties.
- Worked with wrapping, ordering, alignment, and flexible sizing.

**P11: Newspaper Grid**

- Created a newspaper-style layout using CSS Grid.
- Practiced rows, columns, and grid areas.

**P12: Projects Grid**

- Created a project gallery using CSS Grid.
- Practiced responsive card layouts.

**P13: Flexbox vs Grid**

- Compared CSS Flexbox and CSS Grid.
- Practiced choosing appropriate layout systems for different designs.
